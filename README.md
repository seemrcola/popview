# PopView

Tauri 2 + Vue 3 的本地图片查看器，支持目录树、搜索、网格/列表、单图缩放和自由画板。保留波普风格的现有界面，不引入全局状态管理或数据库。

## 开发与验证

```bash
npm install
npm run tauri dev
```

桌面开发需要 Rust 及 Tauri 对应平台的构建依赖。单独运行 `npm run dev` 可在 `http://localhost:1420` 检查欢迎页；普通浏览器不能调用原生文件选择器，界面会给出明确提示。

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run check
```

`npm run check` 顺序运行前端回归测试、类型检查与生产构建、Rust 测试。前端测试使用 Vitest、Vue Test Utils 和 Happy DOM；测试 DOM 环境并不等于真实 WebView 视觉验收。

## 代码边界

### 界面风格

保留 PopView 的波普插画和文件夹交互，以奶油白内容区、薄荷绿侧栏、粉色选中态和黄色主操作传达轻量波普风。“选择文件夹”采用 500 字重、1px 墨黑细边、5px 圆角的黄色按钮，不加硬阴影，保留悬停、按下和键盘焦点反馈；工具分组、图片卡片、文件夹名称和目录选中态不加黑框或硬阴影。内容层级优先使用留白、字重和底色，列表只留轻分隔。深色图片查看器保持安静，不为图片增加色彩滤镜或悬停放大。常用文字以 12–15px 为主，公共色彩和交互变量定义于 `src/style.css`，组件样式继续由各组件维护。新增过渡均提供 `prefers-reduced-motion` 降级。

视觉验收应在 Tauri 窗口内检查欢迎页、含长文件名的目录、网格/列表、空目录、搜索、键盘焦点、单图和画板；普通浏览器只能直接打开欢迎页，不能替代原生文件选择及媒体协议验收。

## 目录与缓存契约

- Rust 原生选择器读取新根目录成功后才提交新会话；取消或读取失败保留旧目录。
- 目录树与内容区共享缓存，展开和选择同一路径复用正在执行的请求。
- `session` 明确标识根目录会话，`viewVersion` 明确标识已提交的导航/刷新。旧请求不能修改新会话，旧可见性事件不能重新排队。
- 每个目录具有 `revision`、`stale` 和失效版本；外部模块通过只读查询访问，不通过缓存对象或数组身份推断刷新。
- 刷新当前目录重新读取本层，标记已缓存的直接子目录过期，并使子文件夹封面失效。再次进入过期子目录时重新读取。
- 封面优先复用新鲜目录数据；否则仅对可见卡片采样，最多两个采样请求并发。每次最多检查 256 个直接条目，找到三张图片即停止，不递归、不全量排序。
- 切换页面后，屏幕外尚未开始的封面任务不再排队。已开始的文件系统工作可以完成，但不会写入新会话。
- 当前会话的目录元数据保留至切换根目录；暂未实现文件系统监听或元数据缓存容量淘汰。外部修改后请刷新相关目录。

## 图片加载与容量边界

- 图片/文件夹集合每页最多 120 项；分页只影响列表，单图查看器仍可浏览当前搜索结果中的全部图片。
- 网格/列表切换同时作用于图片和文件夹。列表中的文件夹置于图片前，显示图标、名称和类型，点击进入目录；列表模式不加载文件夹封面，切换模式保留当前页。
- 两种预览模式共用虚拟缩略图条，长目录不会创建上万个缩略图按钮。
- 网格、列表、封面和缩略图条只请求缩略图。进入单图模式或添加到画板时才读取原图。
- 缩略图最长边 384 像素，保持宽高比，不放大小图，并应用可读取的 EXIF 方向。
- 缓存位于系统应用缓存目录下的 `thumbnails` 子目录；键包含规范化路径、文件大小、纳秒修改时间和缩略图版本。
- 缓存预算为 256 MiB，新文件写入前按生成时间清理旧缓存；写入先落临时文件再重命名。缓存只在请求时维护，不需要数据库。
- 原图与缩略图各有独立的两路请求限流，打开原图不必等待缩略图队列；缩略图生成与缓存写入串行，避免重复生成及同时解码多张大图。单文件限制 128 MiB，缩略图解码限制最大边 20000 像素及 256 MiB 解码器分配预算。
- JPEG、PNG、GIF、WebP、BMP 支持生成静态缩略图，GIF 封面使用静态帧。AVIF、HEIC、HEIF 暂无缩略图解码器，列表显示占位，仍可打开原图；原图能否显示取决于平台 WebView 的格式支持。

## 安全边界

- 前端不能传入路径来授权新根目录；`choose_directory` 只能通过 Rust 调用原生目录选择器。
- 目录读取和封面采样携带会话标识，Rust 检查当前会话、规范化路径、根目录范围和符号链接；相对路径、`..`、越界路径和符号链接被拒绝。
- 原图和缩略图统一通过受校验的 `media` 协议提供。切换根目录后，旧会话不能发起新的文件读取。
- 不再启用全磁盘 `asset` scope；媒体协议仅提供允许扩展名的图片，禁止提供普通文本或任意文件。响应不缓存到 WebView，避免刷新后继续显示旧内容；缩略图复用由磁盘缓存负责。
- 开启生产与开发 CSP，只允许应用资源、受控媒体协议、IPC 及现有 Google Fonts；开发 CSP 另外允许本地 Vite/HMR。
- 前端 capability 仅保留调整窗口大小和居中的权限，不开放通用文件系统和原生选择器 JS 权限。
- 这不是对本机恶意进程的操作系统沙箱：路径检查不承诺抵御另一个进程同时替换目录的竞争攻击。

## 回归覆盖与人工验收

自动测试覆盖目录请求去重、导航响应乱序、会话切换、失败回退、刷新失效、可见封面并发/销毁、列表分页、缩略图虚拟化、模式状态保留、焦点恢复，以及 Rust 的路径授权、符号链接拒绝、协议解码、缩略图尺寸、文件变化失效和缓存淘汰。

发布前仍应在目标平台的真实桌面窗口检查：选择/取消目录、原图显示、单图缩放、切换模式保留状态、拖入和缩放画板图片、Escape/焦点恢复，以及包含大量高分辨率图片时的内存和滚动表现。单元测试不替代这些原生交互和性能验收。
